# GlobalJob AI Android MVP

This is a Kotlin + Jetpack Compose Android starter for GlobalJob AI.

## Current MVP UI
- Home dashboard
- Matching jobs
- Application tracker placeholder
- Profile/preferences placeholder

## Build
Open this folder in Android Studio, allow Gradle sync, then:
Build > Build Bundle(s) / APK(s) > Build APK(s)

## Production next steps
Connect a secure backend for CV parsing, AI matching, authentication, job-source integrations, document generation, and application tracking. Keep API secrets on the backend, never in the APK.
